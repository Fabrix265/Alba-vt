# Clips de Alba PNGTuber

Pon aqui tus clips exportados con nombres como `idle.apng`, `idle_talk.apng`, `thinking.apng` o `coding.webm`.

Formatos: PNG/GIF/APNG/WebP para imagenes y WebM/MP4 para video. Los nombres y el bucle se configuran en `config/assets.json`; las escenas los referencian con `clip` y `talkingClip`.

El contenido de `assets/pngtuber` esta ignorado por git. Solo se versionan este README y el `.gitkeep`.
